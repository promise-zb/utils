# 图纸面积计算

上传图纸图片，识别文字后出一份面积结果。

## 结果

能算的时候：

```
总面积：93.42 m²
卧室1：12.87 m²
餐厅：11.88 m²
A：1.98 m²
```

- 图上有房间名就用图上的字。同一个名字出现多次，按从上到下、从左到右编成卧室1、卧室2。
- 格子能算但图上没字，按 A、B、C 编号。
- 图上有名字但没有对应长度，不计算，列在 `未计算`。
- 整张图没有任何长度，也没有㎡标注：`没有长度，无需计算`。
- 有长度但拼不出闭合区域：`识别到长度，但没有可计算的区域`。

## 怎么算

1. 图上有㎡时，直接用标注，不再用尺寸反推。
2. 没有㎡时，取图纸外圈的横向、竖向尺寸链。
3. 横竖都能拆成两段以上，按矩形格子算面积。左右竖向尺寸一致时，每一列都用这组高度。左右不一致时，相同的开头一段算通长，剩下的只算最左列和最右列。只有一侧有竖向尺寸时，只算这一侧的外列。中间没有独立尺寸的房间不计算。
4. 横竖都只有一个总尺寸时，只给出外轮廓总面积，房间不逐个计算。
5. 小于 0.2㎡ 的格子忽略。长度按毫米，整数且是 10 的倍数；带 m、米、cm、mm 的按单位换算。

不规则房间（飘窗、缺角）按尺寸链围成的矩形估算。结果依赖文字识别，水印和标题栏里的数字可能干扰。
